# Architecture Decision Records (ADRs) Index

This document is the master index for all Architecture Decision Records (ADRs) used by Cloud Novel.

## Purpose

Architecture Decision Records document permanent engineering decisions.

Each ADR records:
- The problem
- The decision
- The reasoning
- Alternatives
- Consequences

Each ADR lives in its own Markdown file.
The ADR Index provides navigation and project history.

## ADR Lifecycle

Proposed
↓
Accepted
↓
Implemented
↓
Superseded
↓
Deprecated
↓
Archived

- **Proposed:** The ADR has been drafted and is under review.
- **Accepted:** The decision has been approved and is ready for implementation.
- **Implemented:** The decision has been fully realized in the codebase.
- **Superseded:** A new ADR has overridden this decision.
- **Deprecated:** The decision is no longer relevant but not yet fully removed.
- **Archived:** The decision is kept for historical purposes only.

## ADR Naming Convention

Files must follow this naming convention:
- `ADR-001-premium-pdf-novel-reader.md`
- `ADR-002-the-published-page-is-sacred.md`
...

**Important Rules:**
- Never renumber ADRs.
- Never reuse numbers.
