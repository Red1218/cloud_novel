## Welcome
Welcome to the Cloud Novel AI Context System. This document is the starting point for any AI assistant (Claude, ChatGPT, Codex, Kimi, Gemini, etc.) joining the project. ## Project Objective
Cloud Novel is a comprehensive web platform for creating, reading, and interacting with novel content. Its goal is to provide a seamless, robust, and scalable platform for readers and authors alike.
